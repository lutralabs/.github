# Lutra Labs

**LutraID by Lutra Labs** is a platform for issuing and verifying digital credentials for the EU Digital Identity (EUDI) Wallet under eIDAS 2.0. Organizations use it to issue credentials to EUDI Wallets and to request and verify them, through a web console and an API, either on LutraID Cloud or self-hosted.

## Who it is for

- **Issuers**: public bodies, universities and companies that issue credentials such as diplomas, licences, memberships or employee IDs to wallets.
- **Relying parties**: services that request and verify credentials from a wallet instead of collecting documents.
- **Integrators**: software vendors and platforms that build issuing and verification into their own products over the API.

## Standards

OpenID4VCI, OpenID4VP, SD-JWT VC, ISO/IEC 18013-5 mdoc and the eIDAS 2.0 / EUDI Architecture and Reference Framework.

Lutra Labs is an associated partner in the WE BUILD EUDI Wallet large-scale pilot.
